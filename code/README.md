# R Code

All scripts are run from the project root, e.g. `source("code/q1/q1_01_eda.R")`.

- `00_setup.R` - shared setup used by every script (packages, data, helpers).
- `q1/` - Q1 injury risk analysis (owned scripts, see notes/q1-plan.md).
- `q2/`, `q3/` - one folder per question, same structure.
- `exploratory/` - early exploration (01-02), first starter models (03-05) and the
  question-scoping evidence (06). Superseded or rejected work is kept deliberately.
